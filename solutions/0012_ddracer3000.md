# DDracer 3000

## Hint

After you rendered this map you are greeted by a text:

"I want to sit so bad on my ddracer 3000 where did I park it again?"
"How deep did I park it? It's time to play some game"

## Solution

"I want to sit so bad on my ddracer 3000 where did I park it again?" and
"How deep did I park it" is explicitly asking for the Y-Cooridnates you have, if you sit on the ddracer 3000 in the map chill woods

"It's time to play some game" is asking for a time. It also tries to reference another map by talking about a game. The game meant here is `Noita` (see [0010_noita.md](0010_noita.md)).
It also mentions a time. Meaning you should enter the Y-Coordinate as a time.

This results in the following command:

`/maprender name:Noita time:476000` which reveals a new puzzle

## Extra notes:

There are many different game related maps in ddnet (i.e. Flappy Bird) (more than I thought). The player explicitly got the Noita map before, but this was maybe confusing. I should have clarified this with "other game".

The time that is entered is also meant to be in seconds and not milliseconds. I hoped that players learned that from the rick roll puzzle [0008_teini.md](0008_teini.md).

Gladly the puzzle did not care about extra x/y coordinates set for the Noita map
