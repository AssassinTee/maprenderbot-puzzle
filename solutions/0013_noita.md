# Noita

## Hints

Rendering Noita at the right time reveals a new puzzle

The key is greater than 3

run_vigenere

FHVMM APT UEU MJHVCHL

## Solution

run_vigenere is a map, that you can render which reveals the "The Thinker" statue. It's also a reference to the [vigenere cipher](https://en.wikipedia.org/wiki/Vigen%C3%A8re_cipher) which was used to encode 
"FHVMM APT UEU MJHVCHL".

"They key is greater than 3" is a reference to the previous unused DarKcHip_greater_3 map which renders a key ([0005_DarKcHip.md](0005_DarKcHip.md)). This means the cipher key is "DARKCHIP".

Deciphering the message reveals "Check the Red channel". If you render the map `Red Channel` with `/maprender name:Red Channel` the next clue is revealed
