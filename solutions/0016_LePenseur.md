# Le Penseur

## Hint

Rendering "Le Penseur" reveals a clue: "It's time for the mining drill"

## Solution

This is a reference to the previous puzzle from [0012_ddracer3000.md](0012_ddracer3000.md). It asks for a time and the drill contains the number 3000.
Entering the time in seconds into "Le Penseur" (similar to the previous puzzles) reveals the winning screen.

`/maprender name:Le Penseur time:3000000`
