# xQc

## Hint

If you just render this map with /maprender name:xqc it's empty

## Solution

If you enter the coordinates from the previous map [0010_noita.md](0010_noita.md) you get a screenshot from the existing ddnet map `Chill Woods`.
If you look closely, you can see that it contains a mining drill with the name `DDracer 3000`.
Rendering `/maprender name:DDracer 3000` reveals the next hint.
