# Red Channel

## Hint

This map contains a QR code that reads the following text:
"the ddnet-maprender-bot has a weird fist issue"

## Solution

This is a meta puzzle. This puzzle was run on a discord bot which is inside a github repo. If you follow the authors discord profile to his github profile you can find the publicly available ddnet-maprender-bot
https://github.com/AssassinTee/ddnet-maprender-bot/issues/1 , where the first issue also has a puzzle label.

The first issue contains the text `The map named after the French statue doesn't contain it, instead it is visible in run_vigenere`.
`run_vigenere` contains the statue of "The Thinker" which is in france and called "Le Penseur" in French.

You reveal the next clue by rendering "Le Penseur" with
`/maprender name:Le Penseur`
